          Sign releases on another computer

          The 12 words rebuild the same Android key and certificate, so releases from the new computer update the installed app.

          1. Install the tools this page needs, plus OpenSSL 3 (brew install openssl on macOS).
          2. Clone the repository and run pnpm install at its root.
          3. Run pnpm --dir tools/release keystore:restore and type the 12 words. Add --force if a keystore is already in ~/.satsigner.
          4. Check that the printed certificate SHA-256 is E0:D6:E6:92:FA:D1:AA:16:26:FF:54:9A:CE:E3:47:C2:EB:CE:8B:E5:0D:07:44:CB:D0:D3:A6:75:39:F2:7E:D7. Any other value means a word is wrong.
          5. Start this page with pnpm --dir tools/release dev and sign in with the same npub.
          6. Publish. The existing link between the key and your npub is found and renewed only when it nears expiry.

          Type the words only into the restore prompt. Never save them in a file, a chat or the repository.

          Check the 12 words against this key

          The check runs in a terminal so the words never pass through this page. It says whether the words are valid, and whether they rebuild the keystore on this computer.

          1. Run pnpm --dir tools/release keystore:confirm and type the 12 words. Add --next to check the words of a rotated key.
          2. Valid words that do not match means another phrase, or a word swapped for another valid one. Not 12 valid words means a typo.
          3. Run pnpm --dir tools/release keystore:status for the same report as this tab.
          Rotate to a new signing key

          Rotate only when the old key leaked or must be retired. Android accepts an update from a new certificate only when the APK carries a signing lineage (APK Signature Scheme v3) back to the old one. Zapstore rejects a release whose certificate is neither the app's current one nor linked to it by lineage.

          1. Check the current words first. Rotation needs the old key, and every release keeps signing with it.
          2. Run pnpm --dir tools/release keystore:rotate. It writes a new key to ~/.satsigner/next, the lineage to ~/.satsigner/release.lineage, and prints 12 new words. Write them down next to the old ones.
          3. Release builds then sign with both keys: Android 13 and later use the new key (v3.1), older versions keep the old one.
          4. Publish once. The publisher links the new certificate to your npub with a new identity proof, so Zapstore accepts it.
          5. On another computer, restore the old key with keystore:restore, then the new one with keystore:rotate --restore. The lineage is rebuilt from both keys.

          Never delete the old key or its words after a rotation. Without the lineage, every user must uninstall and reinstall.
