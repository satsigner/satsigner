      Each option runs a clean prebuild, which deletes the android folder, then saves a copy under dist/apks.

      Branch

      Includes every CPU architecture, so the file is large. The package id follows this branch, so the install sits beside the Zapstore app and will not replace it.

      Production

      Uses the production package id with no branch suffix, so installing it replaces the real Satsigner app. A later store update can fail if this APK was signed with the local test key.

      Pixel 8, 9, or 10

      arm64-v8a only, which those Pixels use. Smaller and faster to build. It will not install on x86 emulators or 32-bit phones. The package id still follows this branch.
